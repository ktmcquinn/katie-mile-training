First-time setup (one-time)
  1. In your code repo, open Katie_Mile_Training_Calendar_Interactive.html and find the SUPABASE_URL / SUPABASE_ANON_KEY constants near the top of the <script>. Paste in the values from your Supabase project's Settings → API page. Commit + push.
  2. In Supabase, open SQL Editor → New query, paste the contents of supabase-setup.sql, and click Run.
  3. In Authentication → URL Configuration, set Site URL and add a Redirect URL pointing to your Vercel/Netlify site.
  4. (Optional but recommended) In Authentication → Providers → Email, you can disable "Confirm email" so signup is instant — your call. Disabling speeds you up; keeping it adds a confirmation-link step.
  5. (Optional, after your account is created) In Authentication → Sign In / Up, toggle off "Allow new users to sign up" — that locks the project to just you.

Setup instructions (one-time)
  1. Go to strava.com/settings/api and create an API app. Use your Vercel domain (e.g. katie-mile-training.vercel.app) as the Authorization Callback Domain (no https://).
  2. Copy your Client ID and Client Secret.
  3. In your Vercel dashboard → Settings → Environment Variables, add STRAVA_CLIENT_ID and STRAVA_CLIENT_SECRET with those values. Apply to Production + Preview + Development.
  4. Re-run supabase-setup.sql in Supabase to add the strava_tokens table.
  5. Redeploy on Vercel so the new env vars take effect.
  6. Sign in to your app (Cloud Sync), then click Connect Strava above.
